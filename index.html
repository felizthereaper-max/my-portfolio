What I Am Learning

HTML

HTML, or HyperText Markup Language, is used to create the structure of webpages. I am learning how headings, paragraphs, links, images, lists, tables, forms, sections, articles, and other HTML elements work.

CSS

CSS is used to style webpages. I am learning about colors, spacing, layouts, typography, responsive design, animations, and other visual effects.

JavaScript

JavaScript allows websites to become interactive. I want to learn how buttons, menus, animations, forms, games, and other interactive features can be programmed.

Web Development

My long-term goal is to understand the complete process of creating a website, from writing code to testing it and finally publishing it online.
